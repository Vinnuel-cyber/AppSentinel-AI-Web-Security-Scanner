# CVSS v4.0 Risk Engine Specification & Implementation

This document details the architecture, mathematical scoring model, MacroVector lookup algorithm, and severity ratings implemented in AppSentinel's CVSS v4.0 Risk Engine (`app/security/risk_engine.py`).

---

## 1. Introduction to CVSS v4.0

The **Common Vulnerability Scoring System version 4.0 (CVSS v4.0)** was published by FIRST (Forum of Incident Response and Security Teams) in November 2023. CVSS v4.0 replaces CVSS v3.1 formulas with a discrete MacroVector classification methodology that resolves previous mathematical inconsistencies and better distinguishes vulnerable systems from downstream impacted systems.

AppSentinel implements the **CVSS v4.0 Base Metrics Group**, producing fully compliant vector strings:
```
CVSS:4.0/AV:<X>/AC:<X>/AT:<X>/PR:<X>/UI:<X>/VC:<X>/VI:<X>/VA:<X>/SC:<X>/SI:<X>/SA:<X>
```

---

## 2. Base Metric Groups & Explanations

### 2.1 Exploitability Metrics
1. **Attack Vector (AV)**:
   - `N` (Network): Remotely exploitable over Internet or untrusted networks.
   - `A` (Adjacent): Exploitable from the same physical or logical network (e.g., local subnet, Bluetooth).
   - `L` (Local): Requires interactive local console, shell, or file system access.
   - `P` (Physical): Requires physical device tampering.
2. **Attack Complexity (AC)**:
   - `L` (Low): Reliable, deterministic execution without evasion or race condition dependencies.
   - `H` (High): Requires specialized non-standard conditions, timing, or bypasses.
3. **Attack Requirements (AT)**:
   - `N` (None): No prerequisite deployment conditions required.
   - `P` (Present): Requires specific deployment architecture, non-default configs, or race windows.
4. **Privileges Required (PR)**:
   - `N` (None): No authentication required.
   - `L` (Low): Requires basic authenticated user permissions.
   - `H` (High): Requires administrator, root, or elevated privileges.
5. **User Interaction (UI)**:
   - `N` (None): No victim action required (server-side flaws).
   - `P` (Passive): Requires victim to interact passively (e.g., visiting an attacker-crafted link).
   - `A` (Active): Requires victim to perform explicit deliberate actions (e.g., uploading malicious files).

### 2.2 Vulnerable System Impact Metrics
- **Vulnerable System Confidentiality (VC)**: `N` (None), `L` (Low), `H` (High)
- **Vulnerable System Integrity (VI)**: `N` (None), `L` (Low), `H` (High)
- **Vulnerable System Availability (VA)**: `N` (None), `L` (Low), `H` (High)

### 2.3 Subsequent System Impact Metrics
- **Subsequent System Confidentiality (SC)**: `N` (None), `L` (Low), `H` (High)
- **Subsequent System Integrity (SI)**: `N` (None), `L` (Low), `H` (High)
- **Subsequent System Availability (SA)**: `N` (None), `L` (Low), `H` (High)

## 3. MacroVector Scoring Algorithm

CVSS v4.0 groups the 11 base metrics into 5 equivalence dimensions (**EQ1** through **EQ5**):

| Dimension | Metrics Evaluated | Levels Evaluated |
|---|---|---|
| **EQ1** | Exploitability: `AV`, `PR`, `UI` | Level 0, 1, 2 |
| **EQ2** | Complexity & Requirements: `AC`, `AT` | Level 0, 1 |
| **EQ3** | Vulnerable System Impact: `VC`, `VI`, `VA` | Level 0, 1, 2 |
| **EQ4** | Subsequent System Impact: `SC`, `SI`, `SA` | Level 0, 1, 2 |
| **EQ5** | Safety & Cross-Boundary Impact | Level 0, 1, 2 |

## 4. Official Qualitative Severity Bands

Scores generated by AppSentinel adhere to the official FIRST CVSS v4.0 rating bands:

```
[0.0]        NONE
[0.1 - 3.9]  LOW
[4.0 - 6.9]  MEDIUM
[7.0 - 8.9]  HIGH
[9.0 - 10.0] CRITICAL
```

---

## 5. Architectural Separation: Mathematical Score vs. Confidence

A critical principle of CVSS v4.0 is the **complete decoupling** between mathematical impact scoring and scanner confidence:
1. **CVSS v4.0 Score**: Evaluates intrinsic technical severity assuming the vulnerability is confirmed. A confirmed SQL injection and a suspected SQL injection have the identical CVSS base score (9.2).
2. **Scanner Confidence**: Handled exclusively in operational risk prioritization (`RiskPrioritizer`). Unconfirmed or heuristic probes are downranked operationally without corrupting the objective CVSS vector.
