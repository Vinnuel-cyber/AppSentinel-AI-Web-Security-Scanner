# AppSentinel Professional PDF Report Generator (V9)

## 1. Overview

AppSentinel **V9 – Professional PDF Report Generator** provides publication-grade, academic, and portfolio-ready PDF security assessment reports. The system compiles actual database records into publication-quality documents suitable for technical audits, compliance verification, and leadership briefings.

---

## 2. Supported Report Types

AppSentinel supports three specialized report formats:

### A. Complete Security Assessment Report (`COMPLETE`)
- **Audience:** Lead security engineers, technical auditors, and academic review boards.
- **Contents:**
  - Executive summary and target posture rating.
  - Target application profile and verification credentials.
  - Scan execution telemetry (type, duration, timestamps).
  - Overall risk distribution across Critical, High, Medium, Low, and Informational tiers.
  - OWASP Top 10:2025 categorization matrix.
  - Detailed vulnerability findings with canonical CVSS v4.0 vectors (`CVSS:4.0/...`).
  - Redacted proof-of-concept evidence dumps (payloads, snippets, request/response headers).
  - Remediation guidance and framework-specific code snippets.
  - V8 AI Security Analyst insights (with clear distinction between live AI vs. deterministic fallback).
  - Operational remediation SLA roadmap and methodology conclusion.

### B. Vulnerability Detail Report (`VULN_DETAIL`)
- **Audience:** Software developers, DevSecOps teams, and remediation engineers.
- **Contents:**
  - Fast-path technical defect summaries.
  - Affected endpoint URLs, parameters, and HTTP methods.
  - Precise CWE taxonomies and OWASP 2025 categories.
  - Full CVSS v4.0 vectors and scores.
  - Synthesized remediation blueprints and developer verification procedures.

### C. Executive Summary Report (`EXECUTIVE`)
- **Audience:** C-Suite executives, compliance officers, and project stakeholders.
- **Contents:**
  - Executive-level security posture scorecard.
  - Target profile and scope summary.
  - High-level risk distribution breakdown.
  - Systemic root-cause overview.
  - Prioritized strategic initiatives (P1 through P5 operational tiers).

## 4. Integrity and Storage

All generated reports are persisted under the configured `REPORT_FOLDER` (`reports/` by default). Each report record stored in the database captures:
- `file_path`: Absolute path verified with strict traversal checks.
- `file_hash`: SHA-256 cryptographic checksum of generated bytes.
- `file_size_bytes`: Byte length of the PDF artifact.
- `created_at`: Generation timestamp in UTC.
